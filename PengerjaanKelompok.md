# Pengerjaan Kelompok — EcoTech

## Project

**Nama Project:** EcoTech — Technology for a Greener Future

**Tema:** Teknologi Ramah Lingkungan dan Edukasi Digital

EcoTech merupakan website edukasi digital yang membahas dampak perkembangan teknologi terhadap lingkungan serta mendorong penggunaan teknologi secara lebih bertanggung jawab dan berkelanjutan.

---

## Pembagian Tugas

### 1. Krishna Yudhistira Pratama

**Bagian: Front-End Development, UI Styling & Form Kontak**

Tugas:

- Membuat komponen tombol (Button) yang dapat digunakan ulang di berbagai halaman.
- Membuat Navbar yang berisi logo, daftar menu, dan tombol Kontak, termasuk menu versi HP.
- Membuat Footer yang berisi deskripsi singkat dan ikon sosial media.
- Menggabungkan Navbar dan Footer menjadi layout utama yang digunakan semua halaman.
- Membuat fitur pengganti mode gelap dan terang.
- Menyusun halaman Beranda yang berisi judul, deskripsi, dan 4 kotak ringkasan.
- Membuat file penghubung ke server untuk mengirim data form ke API.
- Membuat form Kontak dengan kolom nama, subjek, dan pesan, disertai validasi agar tidak kosong sebelum dikirim, serta menampilkan pesan berhasil atau gagal.
- Memasang form Kontak ke halaman Kontak pada bagian yang sudah disediakan di atas FAQ.
- Memastikan pesan dari form masuk dan dapat dicek melalui https://devx2026-post.vercel.app.

## Tools yang Digunakan

- **React**: library untuk membangun tampilan website berbasis komponen.
- **Vite**: build tool untuk menjalankan dan mem-build project dengan cepat.
- **Tailwind CSS**: framework CSS untuk styling tampilan.
- **React Router DOM**: pengatur perpindahan antar halaman.
- **ESLint**: pengecek kerapian dan kualitas kode.
- **Node.js & npm**: menjalankan project dan mengelola library.
- **Git & GitHub**: version control dan integrasi hasil kerja anggota kelompok.
- **Vercel**: hosting agar website dapat diakses melalui link.
- **Visual Studio Code**: editor kode.
- **ChatGPT**: asisten AI sebagai bantuan dalam pengerjaan project.

## Hasil Akhir

Seluruh bagian project akan diintegrasikan menjadi satu website EcoTech yang memiliki tampilan konsisten, responsive, informatif, dan sesuai dengan konsep teknologi ramah lingkungan.
